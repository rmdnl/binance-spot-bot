# VPS deployment guide

This project is an early-stage dashboard scaffold. **Exchange order execution is disabled** in this version. Do not use dashboard controls as evidence that live trading is available.

## Requirements

- Ubuntu 22.04/24.04 or similar
- Python 3.11+
- A dedicated, non-root service account
- Cloudflare Tunnel (`cloudflared`) for public subdomain access without exposing the VPS origin port
- Cloudflare Access policy restricted to your identity before the application login

## Install

Create the service user and working directory, then clone the public repository:

```bash
sudo useradd --system --create-home --home-dir /opt/dca-bot --shell /usr/sbin/nologin dca-bot
sudo -u dca-bot git clone https://github.com/rmdnl/dca-bot.git /opt/dca-bot
sudo -u dca-bot bash -lc 'cd /opt/dca-bot && bash scripts/install.sh'
```

Edit `/opt/dca-bot/.env`. Use a long random `APP_SECRET_KEY`, set the password hash using `python scripts/create_admin_hash.py`, and keep `APP_ENV=development` only for local smoke tests.

For production, configure at minimum:

```ini
APP_ENV=production
APP_HOST=127.0.0.1
APP_PORT=8082
APP_SECRET_KEY=<unique-random-value-at-least-32-characters>
ADMIN_PASSWORD_HASH=<generated-hash>
SESSION_COOKIE_SECURE=true
TRADING_MODE=paper
LIVE_TRADING_ENABLED=false
BINANCE_TESTNET=true
GLOBAL_CAPITAL_LIMIT_QUOTE=120
```

`SESSION_COOKIE_SECURE=true` requires HTTPS. Do not expose port 8082 publicly; proxy it through HTTPS and restrict network access.

## Deployment preflight

After `.env` is configured and dependencies are installed, run:

```bash
cd /opt/dca-bot
bash scripts/preflight.sh
```

The preflight refuses to continue unless `.env` is a regular file with mode `600`, the environment is production, the app remains paper-only, Binance Testnet remains enabled, the origin is localhost-only, secure cookies are enabled, and the full compile/test suite passes. It does not submit exchange orders.

## Start for a local smoke test

```bash
cd /opt/dca-bot
.venv/bin/uvicorn dca_bot.main:app --host 127.0.0.1 --port 8082
```

Open `http://127.0.0.1:8082/login` from the VPS or through an SSH tunnel. The current build can start simulated paper deals and monitor their DCA ladder, average entry, take profit, trailing take profit and stop loss using public Spot prices. It does not submit exchange orders.

## systemd

Review `deploy/dca-bot.service` before installing it. Ensure the service user's permissions allow access to the project and its `data/` and `logs/` directories. Keep the SQLite database and environment file outside version control.

After preflight succeeds:

```bash
sudo cp /opt/dca-bot/deploy/dca-bot.service /etc/systemd/system/dca-bot.service
sudo systemctl daemon-reload
sudo systemctl enable --now dca-bot
sudo systemctl status dca-bot --no-pager
```

Verify locally before putting the dashboard behind the tunnel:

```bash
curl -fsS http://127.0.0.1:8082/login >/dev/null
```

Keep **one Uvicorn worker process** for the current paper worker. Do not add `--workers` until shared state coordination is redesigned and tested.

## Before real trading

Live trading must remain disabled until a separate, reviewed implementation covers Spot-only order placement, idempotency, partial fills, order/trade reconciliation, transactional deal state, emergency-stop behaviour, daily-loss and equity-drawdown enforcement, fee-aware PnL, and Binance Spot Testnet integration tests. A UI toggle alone must never activate live orders.

## Public subdomain through Cloudflare (recommended)

Prefer **Cloudflare Tunnel + Cloudflare Access** instead of opening port 8082 to the Internet. The application should listen only on `127.0.0.1:8082`.

1. Create a Cloudflare Tunnel and install `cloudflared` on the VPS using the installation command generated by Cloudflare.
2. Create a Cloudflare Access self-hosted application for your hostname and allow only your identity. Keep default deny and enable MFA.
3. Map the hostname to `http://127.0.0.1:8082`.
4. Keep `APP_ENV=production`, `SESSION_COOKIE_SECURE=true`, `APP_HOST=127.0.0.1`, `TRADING_MODE=paper`, and `LIVE_TRADING_ENABLED=false`.
5. Confirm Cloudflare Access blocks an unauthenticated identity and the app password remains enabled as a second layer.
6. Ensure the VPS firewall/security group does not expose TCP 8082 publicly.

Official guides: [Create a Cloudflare Tunnel](https://developers.cloudflare.com/tunnel/get-started/) and [Publish a self-hosted application with Access](https://developers.cloudflare.com/cloudflare-one/access-controls/applications/http-apps/self-hosted-public-app/).

## Paper worker operation

In paper mode, the app checks active simulated deals every `PAPER_POLL_INTERVAL_SECONDS` (default 10 seconds). It uses public market prices only and never sends orders to Binance. Keep a **single Uvicorn worker process** so multiple processes do not poll and update the same paper state concurrently. No live execution worker is implemented.
